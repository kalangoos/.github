# Como contribuir com o KalangoOS

Cada repositório da organização tem o próprio `CONTRIBUTING.md` com os detalhes de build e de teste; este arquivo é
o padrão para os que ainda não têm.

1. **Abra ou comente uma issue antes de começar**, dizendo o que pretende fazer.
2. **Leia o `AGENTS.md`** do repositório se você trabalha com um agente de código: as regras valem para pessoas e
   agentes.
3. **Pull requests pequenos**, um assunto cada, com o que você testou e o que não conseguiu rodar.
4. **Sem dados pessoais nem segredos** em código, testes, capturas ou logs.
5. **Falhas de segurança** vão pelo [SECURITY.md](SECURITY.md), nunca numa issue pública.

O guia completo do sistema está em
[kalangoos/kalangoos › CONTRIBUTING.md](https://github.com/kalangoos/kalangoos/blob/main/CONTRIBUTING.md).

Contribuições em português ou inglês são bem-vindas. Todos seguem o [Código de Conduta](CODE_OF_CONDUCT.md).
