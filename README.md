# kalangoos/.github

Arquivos da organização KalangoOS no GitHub:

| Caminho | O quê |
|---|---|
| `profile/README.md` | A página da organização (github.com/kalangoos) |
| `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md` | Padrões da comunidade, usados pelos repositórios que não têm os seus |
| `workflow-templates/` | Modelos de workflow que aparecem em "Actions › New workflow" nos repositórios da organização |
| `.github/` | Modelos de issue e de pull request usados pelos repositórios que não têm os seus |
| `assets/` | Avatar, banner, prévias sociais (1280×640) e cabeçalhos de README de cada repositório |

As artes foram compostas no FigCraft (página "GitHub · artes" do Design System do KalangoOS) a partir da marca do
projeto, sem sombras, brilhos nem degradês, com as cores da paleta. O nome, o mascote e os logos são a marca do
KalangoOS e não estão sob licença aberta.
